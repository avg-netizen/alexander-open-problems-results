# Species equivalence and IAP complexity

These results are now part of the unified paper
[Specieslike clusters with several founders](../06-founding-cohort-species/founding-cohort-species.pdf).
Its [Markdown source](../06-founding-cohort-species/founding-cohort-species.md)
is canonical.

Section 5 proves agreement of the represented infinite
generator-equivalence classes. Sections 6–7 define the observation
space and prove third-level Borel completeness and non-learning;
Appendix A supplies the row-finiteness completeness argument.
These questions originated in this repository.

The old PDF and Markdown paths now contain a short navigation entry
so existing links lead to the current paper. The
[September standalone edition](archive/2026-09-27/README.md) is
preserved as historical material.
