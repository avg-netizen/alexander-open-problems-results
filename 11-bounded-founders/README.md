# Fixed finite founder bounds

This result is now part of the unified paper
[Specieslike clusters with several founders](../06-founding-cohort-species/founding-cohort-species.pdf).
Its [Markdown source](../06-founding-cohort-species/founding-cohort-species.md)
is canonical.

Sections 2–4 define the families and prove chain closure and coverage.
The late-founder example explains why a fixed numerical bound is
different from the founding-cohort condition. Section 5 also includes
the bounded-founder families in the comparison of infinite species
classes.

The old PDF and Markdown paths now contain a short navigation entry
so existing links lead to the current paper. The
[September standalone edition](archive/2026-09-27/README.md) is
preserved as historical material.
